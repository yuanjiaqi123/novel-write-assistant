# novel-writer-assistant

一个可开源的 Codex Skill：根据用户给定的小说设定、大纲或片段，续写小说正文，并同步生成人物小传、场景描写与剧情分支，最终输出完整的小说段落。

## 1. 项目解决什么问题

长篇或片段式小说续写时，常见问题是：世界观跑偏、人物性格崩坏、文风不统一、伏笔丢失、设定不足时 AI 乱编背景。

`novel-writer-assistant` 针对这些问题，让 Codex 在动笔前先盘点既有世界观、人物、时间线与叙事参数，严格遵循用户设定并保持文风统一；信息不足时先向用户提出澄清问题，而不是随意编造。它把续写结果标准化为“每章一张卡片”，方便连载和持续创作。

面向场景：小说续写、片段扩写、剧情分支、连载章节管理。
不适用于：网页抓取、PDF 处理、图形界面、自动生成长篇完整全书。

## 2. 主要功能

- **续写正文**：承接用户给出的世界观、人物设定、大纲或片段，生成完整小说段落。
- **每章一张卡片**：固定输出四部分，便于逐章管理。
  - 章节正文
  - 人物状态注解（含新登场人物小传）
  - 伏笔提示（本章埋下 / 已回收 / 待回收）
  - 可选后续剧情方向（2–4 个）
- **人物一致性**：人物言行符合既有性格，不强行洗白、黑化或突然转变，成长与转变有铺垫。
- **伏笔管理**：维护伏笔账本，标注线索位置与潜在回收方式。
- **节奏控制**：支持慢描写 / 快推进，支持指定每章字数、视角、时态与文风。
- **信息不足时主动澄清**：只输出澄清问题、不输出正文；新增设定以“新增设定 / 待确认”标注。

## 3. 安装方法

本 Skill 无第三方依赖、无脚本，直接复制目录即可使用。

- **全局安装**：将 `skills/novel-writer-assistant` 复制到 Codex 的 skills 目录，例如：

  ```text
  $CODEX_HOME/skills/novel-writer-assistant/
  ```

- **项目级安装**：将目录放在当前项目的 `skills/` 下（本项目已内置）：

  ```text
  项目根目录/skills/novel-writer-assistant/
  ```

- **验证（可选）**：用官方验证脚本检查结构：

  ```bash
  python quick_validate.py skills/novel-writer-assistant
  ```

安装后 Codex 会按需自动发现该 Skill；也可在对话中直接使用 `$novel-writer-assistant` 调用。

## 4. 使用方法

1. 在 Codex 中输入续写请求，附上世界观、人物设定、大纲或片段。
2. 按需补充要求，例如：“第三人称，慢描写，约 400 字，输出完整卡片”。
3. 信息不足时，Skill 会先提出澄清问题；补充后即可继续。
4. 长篇连载时逐章推进：每章结尾会给出可选剧情方向，选择或回复“继续”，再生成下一章。

## 5. 输入输出示例

**输入示例**

```text
校园题材。设定：高二女生林晚，安静内向，习惯在天台写日记；同桌周野，看似散漫但观察力很强。
大纲：林晚发现日记本被人翻动过，怀疑是周野，但她没有证据，只能先试探。
片段：“天台的风把纸页吹得哗哗响。林晚蹲下身，指尖停在日记本被折过的那一页上，过了很久才把本子合上。”
要求：第三人称，慢描写，约 400 字，输出完整卡片。
```

**输出示例**

### 第 1 章 · 风从折页处经过

- **章节正文**：合上本子时，她听见锁扣发出一声很轻的响，像把什么没说完的话也夹了进去。天空正从橘红沉成灰蓝，远处教学楼亮起几扇窗，像很多双没有注意她的眼睛。天台的水泥地还留着午后晒出的温度，风从护栏外一层一层漫上来，吹得她耳后的碎发贴住脸颊。她没有立刻离开，而是用校服袖口把封皮上那道淡痕擦了擦——昨天她明明记得没有。那折角的一页，是她写了一半关于周野的话。……她攥了攥书包带，终于朝楼下走去。

- **人物状态注解**：
  - **林晚**：安静内向，表面克制，内心已由“习惯记录”转为“警觉与试探”；没有证据，只凭直觉怀疑，选择不直接质问。
  - **周野**：本章未直接出场，仅出现在林晚的回忆与设想中；人设不变，他与日记“那一页”的关系成为本章最大悬念。

- **伏笔提示**：
  - **本章埋下**：封皮上的“淡痕”与过于整齐的折角，暗示本子确实被人翻过。
  - **已回收**：承接前文“折过的那一页”。
  - **待回收**：谁翻动了日记；林晚“递出去的那句话”会换来什么反应。

- **可选后续剧情方向**：言语试探 / 设局验证 / 嫌疑人反转 / 心照不宣。
